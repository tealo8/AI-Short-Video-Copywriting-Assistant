# 测试用例文档（test_case.md）

运行方式：`cd backend && python tests/smoke_test.py [base_url]`（默认 http://127.0.0.1:8000）。
测试连接已启动的服务，自动注册临时用户，全流程断言。用例分为 **正常场景** 与 **边界/异常场景** 两大部分。

> 大体积测试素材不入库：批量导入文件可现场用 `GET /api/v1/batch/template` 下载模板后编辑；
> Word/Excel 导出结果在测试脚本内字节级校验（PK 头），不保存样本文件。

## 二、边界 / 异常场景（测试脚本已覆盖或接口层已校验）

| 编号 | 场景 | 行为 | 预期 |
| --- | --- | --- | --- |
| E-01 | 空/超长主题、非法平台、超范围时长 | 前端拦截提示；服务层再次校验 | 422 code=1001，无无效请求落库 |
| E-02 | 字数范围 min>max | 前端 toast 拦截 | 不发起请求 |
| E-03 | 文案超长（>5000 字） | 前端 maxlength+红色计数；服务层 422 | 精简提示 |
| E-04 | 批量超过 50 条 | 前端计数+置灰；服务端上限校验 | 422 提示分批 |
| E-05 | 文件格式不支持/损坏 | 上传区错误卡片 + toast | 明确错误信息，不创建任务 |
| E-06 | 模型输出不合规（标题<6组/时长漂移/类型非法） | JSON→Schema 校验→反馈重试 1 次→质量修复层 | 不返回裸错误；时长自动对齐、标题补足 10 组、类型修正 |
| E-07 | 批量单条失败 | 单条 try/except 记账 items.error | 整批继续，失败可溯源可重试 |
| E-08 | 全部 Provider 不可用 | 降级链全失败 | 502 code=2001 + 友好中文错误；开启演示开关可零模型演示 |
| E-09 | 云端 Key 未配置 | status 显示 cloud 不可用 | 自动使用 ollama/mock，页面提示条说明 |
| E-10 | 未登录访问业务接口 | 401 | 前端跳转登录页并回跳 |
| E-11 | 普通用户访问 /admin/* | 403 code=1003 | 前后端双重校验 |
| E-12 | 分页越界/零数据 | 超出末页 | 返回空 records；前端自动回退第 1 页 |
| E-13 | 软删除后再检索 | is_deleted 过滤 | 不出现在列表；restore 后恢复可见 |
| E-14 | 重复用户名注册 | 唯一约束 | 1001 用户名已占用 |
| E-15 | JWT 过期/篡改 | decode 失败 | 401 code=1002，前端清 token 重登 |

## 三、质量护栏单元校验（quality_service）
- 模拟模型输出：标题仅 4 组、标签缺失、分段时长≠要求、类型非法 → 修复后：
  标题=10、hot/mid/long=3/3/6、分段和==时长、类型=narration、警告清单生成。
- 演示 Mock 数据：结构化字段零缺失，瞬时返回。

## 四、性能与并发
- 批量并发=2（BATCH_MAX_WORKERS 可配），多任务排队状态实时可见；
- 单条失败不中断整批；任务取消标志位在条目间隙生效。
